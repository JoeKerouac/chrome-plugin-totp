# TOTP动态码扩展使用说明

## 功能介绍

这是一个Chrome浏览器扩展，用于生成和管理TOTP（基于时间的一次性密码）动态验证码。

## 主要功能

### 1. 动态码生成
- 实时生成6位TOTP验证码
- 30秒自动刷新
- 点击验证码可复制到剪贴板
- 显示剩余时间进度条

### 2. 配置管理
- 添加、编辑、删除TOTP配置
- 支持自定义名称和密钥
- 配置数据加密存储
- 批量导入导出功能

### 3. 二维码功能
- **显示二维码**：为每个配置生成二维码，方便在其他设备导入
- **扫描二维码**：从网页中扫描二维码自动导入配置

### 4. 自动填充（开发中）
- 自动检测页面中的验证码输入框
- 一键填充对应的TOTP验证码

## 使用方法

### 基本使用
1. 点击浏览器工具栏中的扩展图标
2. 查看当前所有配置的动态验证码
3. 点击验证码数字可复制到剪贴板

### 添加新配置
1. 点击弹窗中的"⚙️ 配置"按钮
2. 在配置管理页面点击"+ 添加新配置"
3. 填写配置名称和密钥
4. 点击"💾 保存所有配置"

### 二维码扫描导入
1. 点击弹窗中的"📷 扫码"按钮
2. 点击"开始选择"
3. 在网页上拖拽选择包含二维码的区域
4. 扩展会自动解析二维码并导入配置

### 显示二维码
1. 在弹窗中点击配置右侧的"QR"按钮
2. 查看生成的二维码
3. 可用其他设备扫描导入

## 测试功能

打开 `test-qr.html` 文件可以测试二维码扫描功能：
1. 在浏览器中打开测试页面
2. 使用扫码功能选择页面中的二维码区域
3. 验证是否能正确导入配置

## 匹配规则配置

### 多种匹配方式
- **域名匹配**: 匹配指定域名 (如: github.com)
- **路径匹配**: 匹配URL路径 (如: /login)
- **路由匹配**: 匹配hash路由 (如: #/auth)
- **正则表达式**: 支持复杂匹配规则 (如: ^https://.*\.example\.com)

### 配置示例

#### 基础匹配
```
域名匹配: github.com
路径匹配: /sessions/two-factor
输入框标识: XXXXXX
```

#### 正则表达式匹配
```
正则表达式: ^https://signin\.aliyun\.com/.*\.htm
输入框标识: 请输入 6 位数字安全码
```

## 安全说明

- 所有密钥数据都经过加密存储在本地
- 不会向任何服务器发送敏感信息
- 建议定期备份配置数据

## 注意事项

- 确保系统时间准确，TOTP依赖于时间同步
- 密钥通常为Base32格式的字符串
- 二维码扫描功能需要在HTTPS页面或本地页面使用
- 某些网站可能有防截图保护，影响二维码识别

## 故障排除

### 验证码不正确
- 检查系统时间是否准确
- 确认密钥是否正确输入
- 验证密钥格式（应为Base32）

### 二维码扫描失败
- 确保选择区域完整包含二维码
- 尝试选择更大的区域
- 检查二维码是否清晰可见
- 确认二维码包含有效的otpauth://链接

### 配置丢失
- 检查浏览器同步设置
- 尝试重新导入配置
- 确保没有清除浏览器数据
